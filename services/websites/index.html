03 How we build it

Six stages. One working outcome.

The stages stay consistent; the questions, decisions and handover are specific to this service.

Typical durationSet after the workflow, integrations and review schedule are scoped.

  1. 01

    Discover

    Review the offer, audience, existing content and the decisions the site should support.

    Output / A concise project brief
  2. 02

    Define

    Set page priorities, navigation, key messages and the path from entry to enquiry.

    Output / A page map and content outline
  3. 03

    Design

    Shape the page hierarchy, visual direction and responsive states before development.

    Output / Reviewed page designs
  4. 04

    Build

    Implement the pages, interactions, forms and agreed content tools.

    Output / A working responsive site
  5. 05

    Test

    Check content, keyboard use, mobile layouts, forms, metadata and image loading.

    Output / A launch-ready review list
  6. 06

    Launch

    Publish the approved site and hand over the files and operating notes.

    Output / A live site and handover

07 Questions

About Websites.

Specifics are confirmed before a project starts.

Can ZEC work with our current content system?

Yes. The project can extend a suitable existing system or use a simpler publishing setup when that better fits the team and content.

Can an existing website be redesigned?

Yes. The work can start with the current site, identify what should stay and replace the parts that no longer support the offer or user journey.

How long does a website take?

Timing depends on page count, content readiness, integrations and review cycles. A project schedule is set after the scope is agreed.

What does a website project cost?

Cost follows the agreed pages, functionality and content needs. ZEC provides a scoped estimate before work begins.
